# Age of Empires Pathfinding

Proyecto desarrollado en Python como práctica de la asignatura **Sistemas Inteligentes**.

## Descripción

Se simula un escenario inspirado en Age of Empires donde varios soldados deben atravesar un mapa generado aleatoriamente hasta alcanzar un objetivo.

El proyecto incluye:

- Generación aleatoria del tablero.
- Representación visual del mapa.
- Simulación del movimiento de los soldados.
- Algoritmos de búsqueda para encontrar rutas.
- Visualización del estado inicial y final.

## Tecnologías

- Python
- Jupyter Notebook
- HTML (visualización)
- Algoritmos de búsqueda
